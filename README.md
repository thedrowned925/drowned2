# Drowned2 — Steam Game Backup

Bu repository, **yalnızca Steam üzerinden indirilen oyunların kişisel yedeklerini** Drowned Distribution Suite altyapısıyla yönetmek için ayrılmıştır.

Kurulum tamamlandığında `drowned1` içindeki launcher, release manager, ortak Python paketi, testler ve GitHub Actions işleyişi burada da bulunacaktır. Eski repository'nin oyun katalogları, manifestleri ve artwork verileri taşınmaz; `drowned2` temiz bir Steam arşivi olarak başlar.

> Bootstrap kurulumu `.github/workflows/bootstrap-from-drowned1.yml` tarafından yapılır.
